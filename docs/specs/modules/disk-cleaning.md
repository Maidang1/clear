# Clear 1.0 安全磁盘清理规格

- 状态：决策完成
- 地图：[Clear 1.0 安全磁盘清理：决策地图](https://github.com/Maidang1/clear/issues/13)
- 依赖：ADR 0001、ADR 0002、ADR 0003

## 用户结果

用户能看到磁盘容量、扫描覆盖和可再生文件的证据；自行选择具体项目；在执行前准确理解哪些文件将移入废纸篓、哪些空间只是估算；最后得到逐项可验证结果和恢复说明。

## 观测与诊断

容量观测使用当前启动卷的公开容量资源值，并显示观测时间。连续两次观测满足以下条件才升级状态：

- `actNow`：可用容量同时不高于总容量的 5% 且不高于 10 GiB；
- `review`：可用容量同时不高于 10% 且不高于 20 GiB；
- `observe`：完整扫描发现至少 512 MiB 的单组候选或合计至少 1 GiB 的候选，但容量未达到前述门槛；
- `clear`：容量不低且完整扫描没有达到 `observe` 门槛；
- `undetermined`：容量关键值不可用，或关键扫描范围不可用。

阈值只决定何时值得查看，不承诺能够释放固定空间。APFS 可清除空间与“移入废纸篓的估算分配大小”分开标注。

## 扫描范围

### 默认规则

- 已知应用的精确 `~/Library/Caches/<bundle-id>` 根：至少 7 天未修改的可再生普通文件；应用必须退出。
- 精确 `~/Library/Logs/DiagnosticReports` 根：至少 30 天的普通诊断报告。

### 高级规则

Xcode DerivedData 与经过验证的 SwiftPM 下载/仓库缓存默认关闭。开启时分别说明重建、网络和首次构建成本，使用独立精确根，并要求相关工具退出。

FDA 不创建新的敏感清理类别，只改善既有精确规则的可见性。权限按根探测。

### 候选硬条件

- 规则 ID、版本、精确根、类别、年龄、预算、风险和应用前置条件均与内置 allowlist 相符；
- 当前用户拥有、同卷、非目录、非 package、非符号链接的普通文件；
- 硬链接数大于 1 的文件默认排除；
- 根、祖先和文件身份在扫描期稳定，候选保存冻结指纹；
- 扫描中身份漂移或单规则预算超限时，丢弃该规则的全部候选。

永久排除用户文档、工程、iCloud/Mobile Documents、照片、邮件、消息、钥匙串、浏览器 profile/cookie/password/history、宽泛 Application Support、共享 App Group、沙盒 Documents、废纸篓、系统卷、外部卷、其他用户和任意输入路径。

## 数据完整性

完整性按规则范围记录。不存在的应用根是“不适用”；权限拒绝、预算超限、不可读元数据、安全边界和扫描中变化是受阻范围。

已完整扫描范围中的候选可以继续预览。`partial` 状态必须显示“在已扫描范围内”，且没有候选时不能显示 `clear`。

## 候选与选择

首层按清理规则分组，显示：

- 生产者或类别、产生原因和重建成本；
- 候选数量、估算分配大小、年龄范围；
- 风险、应用退出要求和扫描覆盖；
- 可展开的相对路径、单项大小与最后修改时间。

首次扫描不默认选择任何候选。用户可选择组或单项；后加入的候选不会自动进入已有选择。

健康概览只展示最重要的诊断发现和一个“查看候选”入口，不直接执行。

## 安全事务

事务预览绑定所有已选文件的身份、规则版本、估算大小、风险和数据完整性。确认文案使用“将 N 个项目移入废纸篓”，不用“释放 N 字节”或“一键清理”。

如果相关应用仍在运行，文件不能进入执行阶段。界面可以另行发起正常退出请求；退出后必须重新扫描和预览。

执行按项目：

1. 写入 journal 意图；
2. 用 no-follow、同卷的安全路径重新验证规则、根、祖先和文件指纹；
3. 移入当前用户废纸篓；
4. 独立验证原路径消失且目标身份匹配；
5. 写入逐项结果。

任一项目为 `uncertain` 后停止所有尚未开始的移动。取消只影响尚未开始的项目。

## 结果、恢复与历史

结果分别展示：

- 已验证移动；
- 复验后跳过；
- 明确失败；
- 不确定；
- 因取消未开始。

界面始终说明文件仍在废纸篓中，清空废纸篓后才可能真正释放空间。Clear 1.0 不自动恢复，也不清空废纸篓；已知目标存在时提供“在废纸篓中显示”和手动恢复说明。

处理历史保留聚合结果 90 天或 500 条；敏感恢复定位最长 30 天；未完成事务 journal 直到 reconcile。

## 资源与验收

- 默认串行扫描规则，元数据并发上限为 2，QoS 为 utility，全程可取消。
- 候选、项目、深度、时间和 I/O 都有显式预算；达到预算必须显示部分结果。
- 测试覆盖规则认证、路径逃逸、符号链接/挂载点/硬链接、身份漂移、应用运行、权限拒绝、预算、确认失效、逐项结果、`uncertain` 停止扩大、取消和 crash reconcile。
- Intel 与 Apple Silicon 使用同一规则与阈值，并分别真机验证扫描、废纸篓、权限和恢复提示。
